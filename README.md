# 🎵 KALLYNI: A Canção do Céu Azul

Este repositório contém os materiais técnicos e de apresentação para a composição orquestral "KALLYNI: A Canção do Céu Azul".

## 🚀 Estrutura do Projeto

### 🎵 Projeto Musical Original
* **`INDEX.HTML`**: A landing page de apresentação da música com player de áudio HTML5.
* **`KALLYNI-Suite-Completa.html`**: Suíte orquestral completa em 6 movimentos.
* **Arquivos de Áudio**:
    * `KALLYNI-O_Ceu_Azul.mid`: Arquivo MIDI para reprodução e análise musical.
    * `KALLYNI-O_Ceu_Azul.musicxml`: Partitura digital em formato MusicXML.
* **`create_midi_simple.py`**: Script Python para geração do arquivo MIDI.

### 🎂 Convite de 15 Anos (React App)
* **`src/`**: Código-fonte da aplicação React
  * `components/KallyniVideoConvite.jsx`: Componente principal do convite animado
  * `App.jsx`: Componente raiz da aplicação
  * `main.jsx`: Ponto de entrada do React
  * `index.css`: Estilos globais com Tailwind CSS
* **`index.html`**: Página HTML principal para o React
* **`vite.config.js`**: Configuração do Vite (build tool)
* **`tailwind.config.js`**: Configuração do Tailwind CSS
* **`package.json`**: Dependências e scripts do projeto

## 🎼 Sobre a Composição

Esta obra é uma peça orquestral com as seguintes características:

* **Duração:** Aproximadamente 40 segundos
* **Instrumentação:** Flauta, Oboé, Violino, Viola, Coro Misto e Harpa
* **Tonalidade:** Lá Maior
* **Estrutura:** Composição em 4 partes distintas
* **Tema:** A jornada de ascensão e realização de uma estrela (Kallyni)

## 💡 Como Ouvir

Basta abrir o arquivo `INDEX.HTML` no seu navegador e usar o player de áudio integrado para ouvir a composição.

Você também pode fazer o download direto do arquivo MIDI através da página.

## 📦 Instalação e Uso

### 🎵 Projeto Musical (HTML Estático)

1. Clone este repositório:
   ```bash
   git clone https://github.com/lianafpinheiro/raow-crubeldade-site.git
   ```

2. Abra o arquivo `INDEX.HTML` ou `KALLYNI-Suite-Completa.html` no seu navegador preferido

3. Aproveite a música!

### 🎂 Convite de 15 Anos (React App)

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Acesse a aplicação em `http://localhost:3000`

4. Para fazer o build de produção:
   ```bash
   npm run build
   ```

5. Preview do build de produção:
   ```bash
   npm run preview
   ```
