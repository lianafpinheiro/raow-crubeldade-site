# 🎵 KALLYNI: A Canção do Céu Azul

Este repositório contém os materiais técnicos e de apresentação para a composição orquestral "KALLYNI: A Canção do Céu Azul".

## 🚀 Estrutura do Projeto

* **`INDEX.HTML`**: A landing page de apresentação da música com player de áudio HTML5.
* **Arquivos de Áudio**:
    * `KALLYNI-O_Ceu_Azul.mid`: Arquivo MIDI para reprodução e análise musical.
    * `KALLYNI-O_Ceu_Azul.musicxml`: Partitura digital em formato MusicXML.
* **`create_midi_simple.py`**: Script Python para geração do arquivo MIDI.

## 🎼 Sobre a Composição

Esta obra é uma peça orquestral com as seguintes características:

* **Duração:** Aproximadamente 68 segundos (17 medidas)
* **Instrumentação:** Flauta, Oboé, Violino, Viola, Coro Misto e Harpa
* **Tonalidade:** Lá Maior
* **Estrutura:** Composição em 4 partes distintas
* **Tema:** A jornada de ascensão e realização de uma estrela (Kallyni)

## 💡 Como Ouvir

Basta abrir o arquivo `INDEX.HTML` no seu navegador e usar o player de áudio integrado para ouvir a composição.

Você também pode fazer o download direto do arquivo MIDI através da página.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com gradientes e design responsivo)
- Python (para geração de arquivos MIDI)
- MusicXML (notação musical digital)
